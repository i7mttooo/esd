# خطة عمل عقد إدارة الخدمات البيئية

صفحة ويب تفاعلية لعرض وتحرير خطة توزيع العمالة والمعدات على الفرق والمواقع، مع تصدير PDF مباشرة من المتصفح.

الملف يعمل بالكامل من جهة المتصفح — لا يحتاج خادم ولا قاعدة بيانات ولا عملية بناء.

## المحتويات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة كاملة (HTML + CSS + JavaScript + البيانات في ملف واحد) |

## التشغيل

افتح `index.html` بأي متصفح. أو انشره على GitHub Pages:

1. ارفع الملفات إلى المستودع.
2. من **Settings › Pages**، اختر الفرع `main` والمجلد `/ (root)`.
3. احفظ، وبعد دقيقة يصير الرابط `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/` جاهزاً.

## الاستخدام

**التعديل** — اضغط على أي نص لتعديله مباشرة: عنوان الخطة، عناوين الأقسام، أسماء المراقبين، الأرقام الوظيفية، أسماء العمال، المواقع، أيام الإجازات، وخلايا الجداول.

**الإضافة والحذف** — أسفل كل قسم أزرار `＋ عامل` و`＋ جدول` و`＋ ملاحظة`، وأسهم `▲▼` لترتيب الأقسام. زر `×` الأحمر يحذف أي عنصر. وفي آخر الصفحة زر `＋ إضافة قسم جديد`.

**الشعار** — اضغط على مربع الشعار أعلى الصفحة وارفع صورة؛ تُصغَّر تلقائياً وتُحفظ داخل الصفحة.

**ألوان الأقسام** — اضغط على النقطة الملونة جنب اسم القسم للتنقل بين ستة ألوان.

**وضع العرض** — زر `وضع التعديل` يخفي كل أزرار التحرير للعرض أو التصوير.

## التصدير

**تنزيل PDF** — تفتح نافذة خيارات فيها معاينة مباشرة تتحدث مع كل تغيير:

- **التوزيع**: صفحة واحدة (تصغير تلقائي ليتسع كل شيء) أو عدة صفحات بالحجم الطبيعي.
- **اتجاه الورقة**: أفقي أو عمودي.
- **عدد الأعمدة**: 3 أو 4 أو 5.

في وضع عدة صفحات لا يُقسَّم أي قسم بين صفحتين، وتُرقَّم الصفحات تلقائياً.

**طباعة** — تفتح نافذة الطباعة بتنسيق مخصص يخفي أدوات التحرير.

**تنزيل نسخة HTML** — يُنتج ملفاً مستقلاً يحمل بياناتك الحالية بداخله، يعمل بدون إنترنت ويمكن إرساله لأي شخص.

## حفظ البيانات

التعديلات تُحفظ تلقائياً في `localStorage` الخاص بالمتصفح، وتبقى بعد إغلاق الصفحة. الحفظ محلي لكل متصفح وجهاز — لنقل النسخة إلى جهاز آخر استخدم **تنزيل نسخة HTML**.

زر `استرجاع الأصل` يعيد البيانات إلى ما هو مخزَّن في `index.html`.

## تعديل البيانات الأولية

البيانات الأصلية موجودة داخل `index.html` في وسم:

```html
<script id="seed" type="application/json"> … </script>
```

بنية كل قسم:

```json
{
  "title": "اسم القسم",
  "color": "#2f46c4",
  "sup": "المراقب: الاسم",
  "code": "II.1.1",
  "blocks": [
    { "type": "people", "rows": [
      { "code": "II.3.1", "name": "الاسم", "sub": "الموقع", "leave": "إجازة الأحد" }
    ]},
    { "type": "table", "headers": ["السائق", "المعدة"], "rows": [["الاسم", "المعدة"]] },
    { "type": "note", "text": "ملاحظة" }
  ]
}
```

أنواع الكتل: `people` (قائمة عمال)، `table` (جدول بأي عدد أعمدة)، `note` (سطر ملاحظة). حقل `leave` اختياري — اتركه فارغاً إذا ما فيه إجازة.

بعد تعديل `seed` يحتاج المستخدم يضغط `استرجاع الأصل` لتظهر البيانات الجديدة، لأن نسخته المحفوظة في المتصفح لها الأولوية.

## المتطلبات

الصفحة نفسها تعمل بدون إنترنت، عدا شيئين:

- خط **Cairo** من Google Fonts — بدونه يستخدم المتصفح خطاً بديلاً.
- مكتبتا **html2canvas** و**jsPDF** من cdnjs لتصدير PDF — بدونهما تظهر رسالة تنبيه ويبقى بقية العمل سليماً.

لتشغيل كل شيء دون إنترنت، نزّل المكتبتين والخط بجانب `index.html` وبدّل روابطها في الملف.

## المتصفحات المدعومة

Chrome و Edge و Safari و Firefox — الإصدارات الحديثة، على الحاسب والجوال.
